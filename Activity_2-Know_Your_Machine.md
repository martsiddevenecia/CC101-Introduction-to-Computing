## III. Background

Hardware falls into four categories: input devices, output devices, the processing/storage unit (CPU, RAM, drives), and ports/peripherals. Windows provides Settings, System Information, Device Manager, and Task Manager to inspect them.

## IV. Procedure

- **Part A** – Physical inspection
- **Part B** – System identification (Settings → System → About)
- **Part C** – Detailed hardware check (System Information / `msinfo32`)
- **Part D** – Device Manager exploration (at least six categories)
- **Part E** – Performance and storage check (Task Manager)
- **Part F** – Software snapshot (optional / bonus)
